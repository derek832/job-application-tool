# Implementation Plan: LinkedIn Job Automator

## Overview

Build a locally-hosted, Docker-based job application automation system consisting of a Python/FastAPI backend (Automator), a Chrome Extension (React/TypeScript), and a Google Apps Script integration. The implementation follows the project structure defined in `dev-workflow.md`, with Python 3.11+, async SQLAlchemy, Pydantic v2, and Hypothesis for property-based tests.

## Notes

- Tasks marked with `*` are optional and can be skipped for faster MVP
- All Python code must pass `ruff` and `black` before commit; all TypeScript must pass `tsc --noEmit` and ESLint
- Secrets are never hardcoded; all secret fields serialize to `"***"` in API responses
- The FastAPI server binds exclusively to `127.0.0.1:7432`
- Property tests use Hypothesis with a minimum of 100 iterations per property
- Each property test is annotated with its property number and the requirements clause it validates
- Integration tests use real in-memory SQLite and mocked external services — no real network calls
